# djsuwkdisowk

Misc scratch utilities for Android. Work in progress, mostly personal
experiments with background work and networking. Nothing here is
documented or stable; expect the contents to change or disappear.

## Layout

- `core/` — experimental module

## Requirements

- JDK 17
- Android SDK (compileSdk 36)

## Build

```
./gradlew :core:assembleRelease
```
